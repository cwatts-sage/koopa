1. **No `--dry-run`** — unlike refresh-schedule.js, there was no way to preview
   scoring without writing to matchups + standings. Risky for a first live run.
2. **Env-var-only credentials** — required `AZURE_STORAGE_CONNECTION_STRING` with
   no fallback, so it could NOT have run from cron the way refresh-schedule.js does

**Fixed both:**

  "0 completed games" (correct — Week 1 unplayed).
