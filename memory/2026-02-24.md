# 2026-02-24 — Private API Fix

## BlueBubbles Private API Helper — FIXED ✅
- **Problem:** Private API helper dylib couldn't inject into Messages.app
- **Root cause:** Messages.app has `library-validation` code signing flag (`flags=0x2000`) — silently rejects non-Apple dylibs
- **NVRAM boot-args don't persist** on Apple Silicon VMs (VirtualMac2,1) — `amfi_get_out_of_my_way=1` gets wiped on reboot
- **Fix:** `sudo defaults write /Library/Preferences/com.apple.security.libraryvalidation.plist DisableLibraryValidation -bool true`
- This persists across reboots via plist — no NVRAM needed
- After fix: `helper_connected: true` confirmed via BB API
- Full Private API features now working: typing indicators, read receipts, tapbacks
