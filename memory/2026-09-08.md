## 🔑 ROOT CAUSE (the real one, took ~15 deploys to find)
```
Worker was unable to load function ping:
'EACCES: permission denied, open '/home/site/wwwroot/ping/index.js''
```
**My shell has `umask 077`.** Every file I create is mode 600. The SWA CLI zips whatever
mode it finds, and the **Linux** Functions worker then can't read them. A single unreadable
file makes the Node worker fail to load, which poisons the whole worker registry →
**every** function 500s, including dependency-free `ping`.

`/api/live` was the lone survivor all afternoon because it is the ONLY function that
imports nothing but Node's builtin `https` — it never reads a deployed file at runtime.

**THE FIX:** build/deploy from a **clean staged copy created under `umask 022`**, then verify
`644` files / `755` dirs *inside the zip* before deploying.
