## ✅ Game Center: direction-of-travel question ANSWERED (was the mockup's biggest unknown)

The mockup shipped with a caveat: *"Direction of travel is my best guess... teams switch
ends at quarters, and ESPN's yardLine is absolute."* **Tested it against real data.**

Used 2025 Wk1 DAL@PHI (event 401772510), all 16 drives:
```
DAL: ascending 0, descending 8  -> CONSISTENT
PHI: ascending 8, descending 0  -> CONSISTENT
```
Sample: `Q1 DAL 53->0`, `Q1 PHI 30->100`, `Q2 DAL 69->23`, `Q2 PHI 19->100`.

**Conclusion: `yardLine` is absolute on a fixed 0-100 axis and each team's direction of
travel is CONSTANT for the whole game — it does NOT flip between quarters.** ESPN
normalises this. So the mockup can simply pin one team to ascending and the other to
descending for all 4 quarters. The feared Q2/Q3 bug does not exist.
